# Student Task & Attendance Manager — No Vite

Tech stack:
- React
- HTML / JSX
- CSS
- Node.js
- Express.js

## Run Backend
Open Terminal 1:
```bash
cd backend
npm install
npm start
```
Backend: http://localhost:5000

## Run React Frontend
Open Terminal 2:
```bash
cd frontend
npm install
npm start
```
Frontend: http://localhost:3000

This version uses Create React App (`react-scripts`) and does NOT use Vite.
